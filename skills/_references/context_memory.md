# 跨问记录与上下文恢复

用于长对话、逐问交接及中断后恢复。每次进入某问的方案、实现、写作或验收前，以及上下文压缩或切换对话后恢复时，执行本规则。记录由助手维护，随已有方案/结果审核更新，不增加用户审批节点。

## 保存什么、何时保存

在赛题工作区维护两层记录，不写入 Skill 安装目录：

- `reports/STATE.md`：简短索引。记录当前问/阶段、唯一或多个待审对象、已批准版本及审核记录位置、当前工作稿位置、依赖关系、阻塞项、探索授权范围与已用预算、下一步和所需文件。全局偏好、共享口径、文献及风格指向已有记录，不复制全文。
- `reports/models/qN.md`：按问保存模型记录。仅在该问实际展开时创建；不同方案/结果版本用独立小节或链接区分，明确当前有效版本、待审版本、被替代或失效版本。已批准内容保留可追溯快照；不能用同名覆盖让旧批准自动指向新内容。

每份模型记录包含以下实际适用内容；建议题不强填公式或求解器：

| 内容 | 记录要求 |
|---|---|
| 版本和决定 | 方案/结果版本、审核状态及审核记录位置；区分候选、已否决、基线、探索和最终采用 |
| 模型建立 | 目标、关键机制、采用理由、核心假设和证据类别；变量定义、单位、索引范围与重要公式；详细推导指向原报告版本/章节 |
| 数据口径 | 来源版本、清洗/聚合原则、训练与验证时段、决策时点可用信息；不得遗漏零值、缺失和百分数等关键解释 |
| 实现与验证 | 算法、参数/配置所在文件、运行方式、实际验证及未通过项；大表和精确参数引用结果文件，不从聊天或图中抄数 |
| 结论与限制 | 最终采用的结论、适用条件、不确定性、尚未解决的问题；保留重要候选被否决的原因，避免无新依据时重新引入 |
| 跨问交接 | 用了哪一问哪个版本；向后问输出什么、字段/单位/粒度/情景含义、源文件与限制，以及哪些后问/图表/段落依赖它 |

记录是已有分析、结果和审核材料的索引与关键语义摘要，不是另建一套独立数值来源。省略详细内容时必须给可定位的来源，不只写“见前文”。

以下时点保存：形成待审方案或结果后、收到具体审核决定后、发生实质修改或实验状态变化后，以及有新增进展的本轮结束前。先写实际材料，再更新索引。不要等到察觉上下文将满才记录，也不要求每条闲聊都重写文件。待审状态同样保存，未完成内容如实标记；没有观察到完成输出的运行不得记为成功。

## 下一问或恢复时如何读取

1. 先读 `STATE.md` 与 `REVIEW_LOG.md` 中相关决定，核对当前阶段、有效版本和批准范围；再读取对应的 `plan.md`/`todo.md` 部分。不能仅凭状态摘要推定用户批准。
2. 读取当前问及它实际依赖的前问模型记录，沿依赖追溯必要的共享假设和限制。不要一次读入所有历史聊天、整套 Skills、原始大表和完整运行日志。
3. 实际打开将要使用的公式、参数、数据和结果源文件的相关部分，核对版本、单位、维度/粒度、时间范围与适用条件。文件存在或摘要写“已检查”不等于本次核对完成；摘要也不能代替实现所需的完整模型表达。
4. 在当前问方案开头写简短“沿用前问内容”表：来源问及批准版本、沿用内容、源文件、限制/适用性、兼容性核对结果。恢复同一已批准任务时只报告当前状态及必要差异，不要求用户重新批准相同内容。

只有确认本步所需依赖有效，才继续已授权工作。整体路线通过仍只允许展开当前问方案；读取后问材料不构成后问实施授权。

## 缺记录、冲突和版本变化

- 老项目没有索引或模型记录时，先从实际题面、报告、代码/配置、结果及可获取的审核会话重建。写明恢复来源；缺少批准证据保留未知，不把生成文件的时间当成批准。
- 聊天摘要、STATE 和模型记录均是恢复入口。用户明确决定决定批准范围；对应版本的模型报告定义科学口径，代码/配置与结果提供实际执行证据。它们发生冲突时不能简单让“最新文件”或代码胜出，应定位差异及影响。
- 可从原始材料查清的遗漏由助手修复记录；若关键假设、公式、结果来源或批准决定仍无法查清，只暂停依赖它的工作并提出具体缺口，不能凭记忆补造。已能确认且不依赖该缺口的工作可继续。
- 新版本未通过前保留原有效版本及适用范围；若发现原版本本身已无效，则不能继续作为有效依赖。按审核规则将实际受影响的下游材料标为 `STALE`，包括间接依赖；更新索引和模型记录中的依赖，不自动重跑所有问题。
- 单纯补记录不创造新的建模结论、结果批准或探索授权。改变科学含义时回原有方案/结果审核。

## 检查是否能恢复

逐问交接时核对：仅凭索引、相关模型记录及其链接，是否能确定“采用了什么、为什么、用了什么数据、结果在哪里、哪些不能推断、用户批准到哪一步、接下来做什么”。缺项先补已有证据。

最终或用户要求的阶段验收，检查一条实际跨问依赖：对照前问已批准表达和源结果，核对后问使用的版本、单位、假设与限制；同时检查失效版本未被引用。文件和格式检查只能证明记录可用，不能证明模型科学有效或保证长上下文零遗漏。
