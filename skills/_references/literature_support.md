# 文献参与建模的工作规则

用于整体路线研究、逐问方案论证及向代码和论文交接依据。文献检索嵌入现有方案审核，不单独增设审批节点，也不等到论文写完才补引用。

## 检索时机与范围

- **整体路线阶段**：从题目领域、任务机制和数据特征检索相关研究，识别常见方法、适用前提、局限和有价值的替代路线。先了解问题，不只搜索已经选中的算法。
- **当前问方案阶段**：围绕拟采用的关键模型、非显然假设、经验公式、外部参数及探索改进补充定向检索，检查来源能否支持本题的用法。引用过的有效证据直接复用，不为每问重复搜同一基础方法。
- **方案发生实质变化时**：检查原文献是否仍支持新假设、模型或参数，按需补查；改变已审核方案时仍按原有变更流程处理。

使用当前可用的检索工具及用户提供的论文。优先原始研究、期刊/会议正式页面、作者公开稿、权威教材与官方技术资料；综述帮助定位方向，再回到关键原始依据。博客、搜索摘要、二手解读可作线索，不能单独支撑关键公式或参数。

用题目领域词、方法/机制词及关键条件组合检索，必要时中英文交叉查找；对关键候选方法查找不适用条件或相反结果，避免只搜支持它的材料。经典方法重来源权威性，领域经验或会变化的资料核对年份；不一律只选最新论文。

候选来源不限于本地知识库。先以问题领域、目标、约束和关键机制寻找研究，再按需要细化到算法；关注不同的问题表达和求解途径，不只在列出的模型名称中循环搜索。清单外方法与自拟数学关系均可进入方案比较，不要求为每问强行补一个陌生方法。

若现有候选忽略关键机制、适用前提不成立或无法达到验证目标，以这个具体缺口扩展检索，比较新方法解决了什么及付出什么代价。没有检索到合适方法时明确范围和限制，允许有依据地自行推导并设计验证；不能以“未收录/没搜到”否定可行思路，也不能据此宣称独创或最优。

不设固定文献篇数，不为每个基础公式硬找论文。当影响方案选择的关键依据已有覆盖、适用性已比较，或剩余缺口与验证办法已明确时，整理材料交现有审核。按项目时间约束控制检索；相同缺口反复检索无新证据时记录限制，不无限搜索。

## 明确三类依据

1. **题面给定**：标明题面或附件位置，不伪装成文献结论。
2. **外部来源支持**：标明来源与具体内容位置，解释它支持模型、假设、公式还是参数。
3. **自行提出或推导**：解释推导、合理性和可验证条件；原创改进可以没有直接先例，但不能声称“文献已证明”，也不能仅凭未搜到相似研究宣称首次提出。

通用方法可引经典论文或权威教材。文献曾使用某算法，只能证明该用法存在，不能证明它对本题有效。模型适用性还须由本题条件、推导和实验共同论证。

## 核实规则

分别核实书目信息与实际支持关系：题名、作者、年份、载体及 DOI/稳定链接应对应同一文献；关键主张要在实际读取的全文、章节、公式、表格或其他可访问原始内容中找到依据。

只读到摘要时，只能据摘要明确表述的内容作有限概括，不能据此声称核实了全文公式、实验细节或参数。DOI 能打开、题目相似或引用标记存在，都不代表论点已核实。不可访问的全文明确记录，不编造页码、原文或未读内容。

来源互相矛盾时比较数据、样本条件、定义和假设，说明采用理由或保留不确定性。检索工具不可用时先检查用户提供和本地已有资料；仍无法核实的依据登记缺口。可提交带明确限制的方案供用户审核，或将其作为自拟假设设计验证，但用户批准也不能把未核实引用变成真实证据。

## 可复用的文献记录

在赛题工作区的 `reports/LITERATURE_REPORT.md` 增量记录检索范围、关键检索词、访问/检索日期、来源及缺口。每条来源用稳定标识（如 L01），另记录它支持的具体模型主张。至少包含：

| 字段 | 内容 |
|---|---|
| 来源身份 | 标识、题名、作者、年份、载体、DOI 或稳定 URL；用户本地材料记录实际文件路径 |
| 核实范围 | 已读取的摘要/全文/章节、页码/公式/表号或可定位小节；无可靠页码时不虚填 |
| 支持内容 | 支持的具体方法、假设、公式或参数；与该问题的对应关系 |
| 适用与差异 | 来源的适用条件、本题有哪些差异、需要怎样改造及如何验证 |
| 状态 | 书目信息是否核实；每项主张标为已核实/部分核实/未核实，并解释范围 |
| 采用决定 | 候选/采用/排除及原因，对应问题与方案版本；记录反例或不采用的关键理由 |

来源可支持多个问题，但各自的支持关系和适用性需分开说明。`ANALYSIS_MODELING_REPORT.md` 通过来源标识引用该记录；正式论文使用所选模板的真实引用方式，不将工作区标识或文件名泄露为正文。

## 交接到实现、写作与验收

- 方案审核材料同时展示“文献方法 → 支持本方案的部分 → 本题差异与改造 → 仍待验证的部分”，让用户能判断采用依据。资料不足的假设明确标注，不藏在参考文献列表里。
- 借用公式或参数时，在建模报告写清变量定义、量纲、取值条件及换算；编码按这个口径实现。文献实验数值不能冒充本题实际结果。
- 每问结果通过后的章节积累，沿用对应方案的已核实来源，把引用放在实际依赖它的论点附近。不得事后寻找相似论文为先前未验证的结论“背书”。
- 验收检查引用真实性、论点支持关系、参数/公式迁移条件和方案版本。发现不支持的引用时修正论断、替换为已核实依据或转为明确的自拟假设并补验证；若改变已批准模型或结论，回到原审核点。
