# 第一问为什么采用传热与水分扩散模型

本说明回应用户关于建模思路与论文依据的追问。对应q1-plan-v1，不改变已给出的方程或自动批准求解。当前模型应称为“有机理依据的可计算简化基线”，尚不是经过本题实验验证的完整干燥模型。

## 1. 从题目需要的答案倒推状态变量

题面要求不同时间、不同半径的温度和含水率，因此未知量必须至少包含T(r,t)、C(r,t)。只有平均温度或平均含水率的模型无法直接提供这些分布。附件1给的是外部激励，未给药材内部观测，所以不具备直接从样本训练内部场预测器的数据条件。

## 2. 从给定参数识别关键机制

| 题面信息 | 物理含义 | 模型中的位置 |
|---|---|---|
| ρ、cp | 材料单位体积储存热量的能力 | 热量蓄积项ρcp Tt |
| k | 药材内部由温差驱动的传热能力 | Fourier导热通量-k∇T |
| D(C) | 用有效扩散系数描述内部水分迁移 | 固定干物质骨架下的相对通量-ρdD∇C |
| h | 烘房空气和药材表面的有限换热能力 | 表面能量交换 |
| hm | 给定传质阻力尺度 | 表面水分交换，但相平衡变量仍需解释 |
| 附件1的Ta、Ca | 随时间变化的外界条件 | 时间依赖边界输入 |
| 圆柱尺寸 | 内部传递的几何与距离 | 圆柱坐标算子、径向/轴向尺度比较 |

这组信息强烈支持“内部传递+表面交换”的机理路线。它不能单独证明空气与药材含水率可直接相减，也不能证明潜热可以忽略。

## 3. 从局部守恒推出方程

在薄圆环上使用“积累=流入-流出”。圆环的传递面积为2πrL，体积为2πrLdr，所以将通量变化除以体积，得到圆柱径向散度(1/r)∂r(r·)。这说明方程中的1/r来自几何；球体或平板会得到不同算子。

热通量由Fourier关系闭合，结合蓄积ρcpT得到ρcpTt=(1/r)∂r(rkTr)。水分使用题面给定的有效D，且在固定、均匀参考干物质密度ρd条件下，将质量守恒中的ρd约去，得到Ct=(1/r)∂r[rD(C)Cr]。Fick型有效扩散是物理闭合，不由守恒定律单独推出；题面给出D是采用它的直接线索。完整推导见models/q1.md第4节。

## 4. 维度与边界是需要单独论证的选择

一般有限圆柱可以有T(r,z,t)、C(r,z,t)。一维径向模型进一步假设关注中部截面且端面影响小。第一问半径2 cm，中截面到端面12.5 cm；1800 s热扩散尺度约1.74 cm、水分扩散尺度约0.30 cm，支持先对中截面作此近似，但不是严格误差界，也不代表长时间问题可不检验轴向效应。

中心采用零径向梯度来自对称性；表面采用有限对流交换来自给定h、hm。对温度而言，不含潜热时-kTr=h(Ts-Ta)就是表面热量平衡。更完整平衡应包含水分蒸发带走的热量kTr=h(Ta-Ts)-Lv js，因此不含潜热的式子只能在相应简化下成立。

水分边界-DCr=hm(Cs-Ca)具有可计算性，但这里Ca应被解释为与固体C相同尺度的等效边界势。若Ca实际为kg水/kg干空气，热力学模型应通过表面相对湿度/水活度、饱和蒸汽压或吸附等温关系映射；题面未提供材料等温关系。单位同为kg/kg不能代替这一步。

## 6. 模型与算法应分开判断

传热/扩散方程是对物理过程的描述；有限体积和BDF是求解该方程的方法。选择有限体积是因为它沿用每层收支结构，方便核对面通量抵消；选择隐式积分是因为细空间网格产生快时间尺度，显式步长会很小。其他合适离散方法也可以求同一个模型。数值收敛能够支持“把所选方程解准了”，不能单独支持“所选方程包含了全部物理机制”。

当前证据评估：空间分布、环层守恒、给定D与物性支持主体路线；径向降维有短时尺度依据；潜热省略和等效水分边界仍是主要模型不确定性。下一步科学判断应针对这些机制与尺度，而不是只增加网格数或添加算法名。
