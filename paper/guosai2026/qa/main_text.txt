考虑变物性与径向收缩的药材
热湿传递及烘干时长预测
摘 要
针对圆柱形药材烘干过程中温湿分布不均、材料物性变化和失水收缩问题，建立由固定
域向收缩域递进的径向热湿传递模型，计算规定位置的温度与干基含水率，并以全域最
大含水率确定烘干时长。
针对问题一，从圆柱环层的热量与水分收支出发，建立常热物性导热方程和含水率
相关的非线性扩散方程，中心采用对称边界，表面采用对流交换边界。对烘房实测数据
作保形三次插值，使用表面加密有限体积法和隐式 BDF 求解，并以 Bessel–Duhamel 展
开独立核验温度。1800 s 时，中心与表面温度分别为 33.5758、36.7879 ◦C，含水率分别
为 2.5500、1.5102 kg/kg，表明预热期升温已传入内部，而失水主要集中在外层。
针对问题二，从初始状态统一采用附录 3 的经验物性，通过含水率对热容量、导热
系数的影响及温度对扩散系数的影响构成双向耦合。3 h 时中心温度为 49.8494 ◦C、含水
率为 1.7662 kg/kg。温度趋于均衡并不意味着水分已达到干燥要求，需继续计算非线性
水分迁移过程。
针对问题三，将全部内部节点的最大含水率与 0.15 kg/kg 之差定义为事件函数，在
前 4 h 观测输入及其后 50 ◦C、0.05 kg/kg 恒定环境假设下进行连续事件定位。区分临界
根与严格低于阈值的报告时刻，结合时空加密结果取烘干时长为 57.4731 h；此时最大含
水率为 0.1499993913 kg/kg，位于中心。
针对问题四，利用给定半径轨迹和比例径向收缩假设，由干物质与水质量守恒推导
材料坐标方程。坐标变换保留内部扩散的 R−2 因子与表面交换的 R−1 因子，避免对干
基含水率错误添加体积压缩项。采用附录 4 物性得到烘干时长 51.0877 h，终时半径为
1.2000 cm，最大含水率为 0.1499989333 kg/kg，计算未超出半径观测范围。
通过解析对照、退化情形、收支与网格加密检验数值实现。第三、四问的细网格临
界时间差分别为 0.5851 s、0.1135 s。结果表明，保留径向梯度、非线性物性和移动表面
有助于一致地求解四问；所报时长为等效模型下的预测，端面效应、潜热及界面平衡关
系仍构成适用限制。
关键词：热湿传递；干基含水率；有限体积法；材料坐标；全域阈值
1
一 问题重述与分析
1.1 问题重述
热风烘干通过烘房与药材表面的热量、水分交换改变药材内部状态。题给药材近似
为长 25 cm、初始半径 2 cm 的圆柱，初始温度 28 ◦C、干基含水率 2.55 kg/kg。附件 1 记
录初期烘房温湿环境，附件 2 记录烘干中的半径变化。本文围绕以下四个任务建立模型。
问题一采用附录 2 参数，计算前 1800 s 的径向温度与含水率分布，在指定七个时刻、
五个半径位置列出结果，并按 1 s、0.1 cm 间隔输出完整数据。问题二从初始状态统一采
用附录 3 经验物性，计算前 3 h 的温湿分布。问题三在问题二模型基础上确定药材各处
含水率低于 0.15 kg/kg 的累计时间，并输出每 6 h 的径向含水率。问题四利用附件 2 的
半径轨迹与附录 4 物性，重新计算收缩条件下的烘干时间和含水率分布。
问题一、二的细时间结果分别保存至 result1.xlsx、result2.xlsx；问题三、四
按 60 s 输出至 result3.xlsx、result4.xlsx。所有结果表保留四位小数，数值推进
和达标判定使用未舍入值。
1.2 模型的递进关系
四问的共同核心是内部扩散与表面交换的共同作用。集中参数模型只能描述平均状
态，难以直接满足题目对不同径向位置的要求。Hussain 和 Dincer 研究了圆柱湿物体干
燥中的二维热湿传递问题 [1]；Kaya 等讨论了圆柱湿物体强制对流干燥的数值建模 [2]。
本文保留径向空间分布，以题给物性和边界数据建立可计算的有效模型，不移植其他材
料的经验参数。
问题一的热物性为常数，且扩散系数仅依赖含水率，故在不显式考虑潜热的条件下，
温度场和水分场可以分别求解。问题二、三的热物性依赖含水率，水分扩散系数同时依
赖局部温度，必须联合推进两个场。问题三的新增任务是对全域最大值进行事件定位，
而不是利用平均含水率或早期失水斜率外推时长。问题四进一步改变空间域：既要描述
材料运动，又要把固定材料坐标的解映射回当前物理半径。
上述任务均为初边值预测问题。烘房条件与半径轨迹在模型中属于输入，不引入题
目没有要求的工艺优化目标。四问均从题给初始状态计算，第二问不拼接第一问末态，
第四问也不读取第三问的最终状态。

二 模型假设与符号说明
2.1 模型假设及其用途
（1） 药材横截面内满足轴对称，材料在周向上均匀，表面交换条件沿周向一致。忽略轴
向梯度和端面交换，建立长度中部截面的一维径向模型。该假设用于将传递方程降
为径向形式；长时间计算的端面影响作为局限保留。
（2） 初始温度与干基含水率均匀；问题一至三半径与长度固定。问题四长度仍取 0.25 m，
骨架按给定 R(t) 作比例径向收缩，干物质不流失。比例收缩用于由外半径轨迹闭
合内部速度场。

3.3 模型的数值求解
（1）空间离散
预热初期，药材表面含水率变化较快，较陡的径向梯度主要出现在外层。为分辨这
一变化，采用节点型有限体积法，在靠近表面处逐步加密网格，并使题目规定的 0、0.1、
6
. . .、2.0 cm 输出位置均为实际节点。将每个 0.1 cm 基本区间细分，在 0 至 1.5、1.5 至
1.8、1.8 至 1.9、1.9 至 2.0 cm 四段内，分别细分为 8m、16m、32m、64m 份，记所得网

八 模型评价与结论
8.1 模型特点
本文围绕同一环层通量结构依次处理常热物性、双向物性耦合、全域阈值和径向收
缩，四问的变量含义、初值与输出口径保持一致。有限体积形式便于保留变系数散度、
处理圆柱中心并检查全局收支；表面加密网格兼顾薄层分辨与题定输出位置。温度解析
展开、制造解和退化测试从不同角度检查实现，降低单一验证方式的局限。
达标计算区分临界根、严格不等式与四位显示，避免将输出整分钟或表格中的 0.1500
误作未经核验的终止条件。收缩问题则从两类质量守恒出发引入材料坐标，明确干基含
水率与体积水浓度的区别，且按当前物理距离输出结果。
8.2 局限与可推广方向
一维模型忽略端面交换，短时中截面的尺度分析不能证明数日预测的端部误差很
小。若补充轴向输出或端面条件，可进一步建立轴对称二维模型，并对温度、最大含水
率位置和达标时长重新核验。
等效水分边界缺少独立吸附等温关系，热方程也未显式描述汽化潜热和水分携焓。

更完整的界面模型需要药材平衡含水率、相变和气固传质数据。仅凭当前方程的收支残
差，不能证明这些机制对真实预测可忽略。

8.3 结论
在题给初值、经验物性和本文明确的等效假设下，问题一 1800 s 时中心温度 33.5758
◦C、表面 36.7879 ◦C，水分损失主要集中在外层；问题二 3 h 时中心温度 49.8494 ◦C、含

模型的报告时长 57.4731 h、给定收缩模型的报告时长 51.0877 h。二者均经未舍入末态
和时空加密核验，且移动边界计算未超出半径观测范围。

152 def manufactured_env(r_surface: float, t: float) ‐> tuple[float, float]:

176 def manufactured_sources(t: float, r: np.ndarray) ‐> tuple[np.ndarray, np.ndarray]:
177 T, C = manufactured_fields(r, t)
178 x2 = (r / R) ** 2
179 u = np.exp(‐t / 600.0)
180 v = np.exp(‐t / 500.0)
181 Tt = 2.0 * (‐1.0 / 600.0) * u * (1.0 + x2)
182 Ct = 0.2 * (‐1.0 / 500.0) * v * (1.0 + x2)
183 Tr = 4.0 * r / (R ** 2) * u
184 Trr = np.full_like(r, 4.0 / (R ** 2) * u)
185 Cr = 0.4 * r / (R ** 2) * v
186 Crr = np.full_like(r, 0.4 / (R ** 2) * v)
187 lapT = np.empty_like(r)
188 lapC = np.empty_like(r)
189 center = r < 1e‐16
190 lapT[center] = 2.0 * Trr[center]
191 lapC[center] = 2.0 * Crr[center]
192 away = ~center
193 lapT[away] = Trr[away] + Tr[away] / r[away]
194 lapC[away] = Crr[away] + Cr[away] / r[away]
195 kn = np.asarray(conductivity(C), dtype=float)

8 def audit_segment(fvm, sol, Ta_fun, Ca_fun, t_end=None, orders=(4,8)):
9 if sol.sol is None:
10 raise ValueError("balance audit requires a dense solution")
11 n = fvm.n_nodes
12 start = float(sol.sol.ts[0])
13 end = float(sol.sol.ts[‐1]) if t_end is None else float(t_end)
14 if not start < end <= sol.sol.ts[‐1]+1e‐9:
15 raise ValueError("audit outside dense‐solution interval")
16 edges = np.r_[sol.sol.ts[sol.sol.ts < end],end]
17 edges = np.unique(edges)
18 z0, z1 = sol.sol(start), sol.sol(end)
19 factor = 2*np.pi*L
20 def energy(z):
21 return float(factor*np.dot(fvm.W,heat_capacity(z[n:])*(z[:n]‐28.)))
22 def quadrature(order):
23 gx,gw=leggauss(order)
24 total=np.zeros(3)

26 aa,bb=edges[j:‐1][:64],edges[j+1:][:64]

28 Y=sol.sol(tt);T,C=Y[:n],Y[n:]
29 Ta,Ca=np.asarray(Ta_fun(tt)),np.asarray(Ca_fun(tt))
30 D=moisture_diffusivity_q2(C,T)
31 Df=2*D[:‐1]*D[1:]/np.maximum(D[:‐1]+D[1:],1e‐300)
32 F=‐fvm.r_half[:,None]*Df*np.diff(C,axis=0)/fvm.dr_face[:,None]

36 factor*np.sum(fvm.W[:,None]*heat_capacity_deriv(C)*(T‐28.)*Cdot,axis=0)])

38 total+=vals@weights

46 def combine(parts):
47 if not parts:
48 raise ValueError('no balance segments')
49 for left, right in zip(parts, parts[1:]):
50 if abs(left['end_s']‐right['start_s']) > 1e‐9:
51 raise ValueError('balance segments have a time gap or overlap')
52 for field in ('M', 'E'):
53 if not np.isclose(left[field+'_end'], right[field+'_start'], rtol=1e‐12, atol=1e‐14):
54 raise ValueError('balance segments have a state discontinuity')
55 I=np.sum([p['integrals_by_order']['8'] for p in parts],axis=0)
56 I4=np.sum([p['integrals_by_order']['4'] for p in parts],axis=0)
57 M0,M1=parts[0]['M_start'],parts[‐1]['M_end']
58 E0,E1=parts[0]['E_start'],parts[‐1]['E_end']
59 mass_denom=max(abs(M0‐M1),abs(I[0]),1e‐18)
60 heat_denom=max(abs(E1‐E0‐I[2]),abs(I[1]),1e‐12)
61 return {
62 'moisture':{'M0':M0,'M_end':M1,'surface_integral':float(I[0]),
63 'relative_residual':float(abs(M1‐M0+I[0])/mass_denom)},
64 'heat':{'E_end_minus_E0':E1‐E0,'composition_correction':float(I[2]),'Q_surface':float(I[1]),
65 'relative_residual':float(abs(E1‐E0‐I[2]‐I[1])/heat_denom)},
66 'quadrature_relative_difference':{'moisture':float(abs(I[0]‐I4[0])/mass_denom),
67 'heat_and_composition':float((abs(I[1]‐I4[1])+abs(I[2]‐I4[2]))/heat_denom)},
