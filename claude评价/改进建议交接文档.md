## 3. 【P0 最高性价比】创新点一：把附件2 从"输入"变成"验证数据"

**这是本次审阅认为最有价值、且成本最低的一点。**

### 3.1 核心思想

当前第 4 问把附件2 的 `R(t)` 当作**已知输入**喂给求解器。但 `R(t)` 其实携带**独立信息**：

若 (a) 干物质骨架守恒、(b) 长度 L 固定、(c) 附录4 的 ρ=760+90C 为真实湿基体积密度，则干物质密度

$$s(C)=\frac{\rho(C)}{1+C}=\frac{760+90C}{1+C}=90+\frac{670}{1+C}$$

满足 `s(C̄)·R² = s(C₀)·R₀²`。由此可**从半径反演出表观平均含水率 C̄(t)**，与第 4 问独立求解出的 C̄(t) 对照——**这是本题唯一可得的"准实验验证"通道**。

### 3.6 复算代码

```python
import numpy as np
from scipy.optimize import brentq
from scipy.interpolate import PchipInterpolator
from openpyxl import load_workbook

base = r"<仓库根目录>"

# 1) 求解所得干基平均含水率（材料坐标下，权重与 ShrinkingFVM 一致）
d  = np.load(base + r"\results\q4_solution.npz", allow_pickle=True)
xi, Y, ts = d["xi"], d["Y"], d["times_s"]
n = len(xi)
faces = (xi[:-1] + xi[1:]) / 2
w = np.diff(np.r_[0., faces, 1.]**2) / 2      # Σw = 1/2
Cbar_solved = (Y[:, n:] * w).sum(axis=1) / w.sum()

# 2) 由附件2 半径反演
wb = load_workbook(base + r"\data\附件\附件2.xlsx", read_only=True, data_only=True)
a = np.asarray(list(wb.active.values)[1:], dtype=float); wb.close()
rt, rv = a[:, 0], a[:, 1] / 100.0
s  = lambda C: (760.0 + 90.0 * C) / (1.0 + C)   # 上界 s(0)=760
s0, R0 = s(2.55), 0.02
R  = PchipInterpolator(rt, rv)

for tq in [1800, 3600, 7200, 10800, 21600, 43200, 86400, 183915.72]:
    Rq   = float(R(min(tq, rt[-1])))
    sreq = s0 * (R0 / Rq)**2
    inv  = brentq(lambda c: s(c) - sreq, 0.0, 2.55) if sreq < 760.0 else None
    j    = int(np.argmin(abs(ts - tq)))
    print(tq/3600, Rq*100, inv, Cbar_solved[j])
```

**(b) 水分轴向渗透尺度**——注意必须用**累计**形式，不能用朴素的 `sqrt(D·t)`：

### 5.3 论证结构（建议照此写）

两阶段论证，**不需要二维 PDE**：

1. **温度**：热在 ~4 h 内全场均匀化（表 a），此后端面对温度场无影响；而达标事件发生在 51~57 h，完全处于均匀化之后。
2. **水分**：决定达标判据的是水分。水分轴向渗透尺度 L_ax = 2.71 cm（Q3），虽不可忽略（已超过半径 R=2 cm 本身），但传播到中截面所需距离 12.5 cm 对应的 erfc 相对扰动仅 **0.109%**。
3. **方向性**：端面提供**额外**干燥面积，故真实三维干燥**快于**一维径向预测——**一维径向结果是达标时间的保守上界**。这一条很重要，它把"误差"变成了"已知方向的保守性"。

### 5.4 措辞纪律

- ✅ 写"erfc 相对扰动约 0.1%，且一维为保守上界"。
- ❌ **不要**写成"端面误差 = 0.109%"。仓库既有纪律已明确警告过同类错误（"不能把 0.07082 写成温度误差 7.08%"）——erfc 参照是**简化比较模型的传播尺度**，不是本题的二维误差界。
- ❌ 不要写"端面可完全忽略"，L_ax=2.71 cm 并不小，只是传不到中截面。

## 6. 【P2】归因实验：物性 vs 几何（解释反直觉结论）

### 6.1 待解释的反直觉点

第 4 问（51.09 h）比第 3 问（57.47 h）**快 6.39 h**。但附录4 的扩散系数**明显更小**：

$$\frac{D_4}{D_3}=\frac{4.2\times10^{-4}}{2.4\times10^{-3}}\exp\!\Big(\frac{0.45-0.30}{C}\Big)=0.175\,e^{0.15/C}$$

| C | 2.55 | 1.0 | 0.5 | 0.15 |
|---|---|---|---|---|
| D₄/D₃ | 0.186 | 0.203 | 0.236 | 0.476 |

**"扩散更慢却干得更快"——评委一定会问。**

> ⚠️ 执行者注意：审阅过程中我一度把指数误写为 `exp(-0.30*C)`（乘法）得到错误比值。题面是 **`exp(-0.30/C)`（除法）**。上表是修正后的值。另注意 C=1 时两种写法数值巧合相同，**不能用 C=1 验证代码正确性**。

### 6.2 量级解释（`[推断]`，尚未验证）

几何增益：达标时刻 R=1.2 cm，`(R₀/R)² = 2.778`

| 阶段 | 物性因子 | 几何因子 | 净效应 |
|---|---|---|---|
| 初期 C=2.55 | 0.186 | 2.778 | **0.516 → 更慢** |
| 后期 C=0.15 | 0.476 | 2.778 | **1.322 → 更快** |

即：**第 4 问前期比第 3 问慢、后期比第 3 问快**；而"各处 C<0.15"这个事件由**中心**、由**最后阶段的慢速失水**控制，后期那 1.32 倍主导了最终 6.39 h 的缩短。附件2 的收缩又高度前载（6 h 内就从 2 cm 缩到 1.374 cm，占全程收缩量的 78%），意味着几何红利在整个后期都已完全兑现。

**这是量级推断，不是已验证结论。仓库三处文件都明确写了"时长差不能全部归因于收缩"，在实验做完之前请保持该口径。**
